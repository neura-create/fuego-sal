# Fuego & Sal — Sitio Web

Sitio web para Fuego & Sal, restaurante.

## Qué es esto

Sitio institucional/landing con presentación del restaurante, menú y contacto.

## Stack

HTML/CSS/JS estático (sin framework)

## Cómo levantarlo en local

Al ser HTML estático, alcanza con abrir `index.html` directamente en el navegador, o correr un servidor local simple:

```powershell
npx serve .
```

## Deploy

Deploy automático vía Vercel/Netlify al hacer push.

Repo: https://github.com/neura-create/fuego-sal
